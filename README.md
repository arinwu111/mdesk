# mdesk

港美股行情数据工作台。一套自己维护的行情与公司行动底稿，附带校验层，保证看到的价格、估值、事件都是可信的。

### ▶ 在线查看：https://arinwu111.github.io/mdesk/

打开即用，无需安装。左边三个是日常视图（自选股、事件日历、次新股），右边五个是运营视图
（异常清单、复权核对、规则库、处理台账、运营报告）。

想直接看这个项目最核心的产出，去 **[复权核对](https://arinwu111.github.io/mdesk/ops/corpaction.html)**
那一页——它用数据源自己的两个字段，证明了它自己算错了复权价。

---

**它不产生投资观点，只保证观点建立在对的数字上。**

打开一只票发现今天 -48%，第一反应必须是「这是真跌，还是 5 合 1 的合股」。
看到 PE 是 -3，得知道是真亏损还是数据源单位错位。这个工具解决的是这一类问题。

## 首轮跑出来的东西

35 只自选股、两年日线共 19239 行、92 笔公司行动、16 条校验规则。

**数据源的派息金额与它自己的复权价互不自洽。**
阿里巴巴 9988.HK 两次派息全部对不上，汇丰控股 0005.HK 九次中最近一次对不上，
隐含倍数均为 **7.847**，恰好等于港币兑美元的联系汇率。
数据源上报的派息是港币金额（正确），但它算复权价时扣减的是美元金额。

阿里每份 ADS 派息 2.00 美元、对应 8 股港股，每股 0.25 美元。
数据源从 118.80 港币的价格里扣掉了 0.25，而不是应该扣的 1.96 港币。

其余 21 只有派息记录的标的倍数全部为 1.0000，包括腾讯、中国石油这类纯港股，
以及阿里自己的美股 BABA。问题只出在同时有美股 ADR 的港股上。

这个结论只用数据源自己的两个字段就能证明，不需要任何外部资料。
影响是阿里全历史 445 个交易日的复权价偏低最多 2.201%，
任何基于它计算的历史涨跌幅、区间收益、波动率都有系统性偏差。

**港股半日市当天成交量整体缺失。**
平安夜、除夕、农历新年前一日共 6 天，港股标的成交量集体为零。
港交所这几天只有早市。这是市场规则不是数据错误，已归为 P2 并写入 SOP 年度事项。

## 两个视图

同一套数据，两个入口。

**日常视图（前厅）**是作为使用者看的：自选股总览、个股详情、事件日历、次新股。

**运营视图（后厨）**是作为维护者看的：异常清单、复权核对、规则库、处理台账、运营报告。

早上先进后厨花十分钟把数据理干净，然后回到前厅安心看盘。
前厅里每行末尾的数据质量角标，就是后厨的产出漏到前厅来的：

| 角标 | 含义 |
|---|---|
| 灰 | 今日无异常 |
| 黄 | 有异常但原因已查明，数字可用 |
| 红 | 有异常且原因未明，该行数字暂不可信 |

## 架构

```
采集层  raw_*          原样落盘，带 source / fetched_at，可重放
   ↓
事件层  events_*       公司行动、前瞻日历。整个系统的枢纽
   ↓
校验层  dq_rules       规则表：规则是数据不是代码，加规则 = 插一行 SQL
        dq_results     命中记录 + 人工处理台账
   ↓
结论层  mart_*         自算复权价、自选股快照（带质量标记）
   ↓
视图层  日常视图 ←──同一套数据──→ 运营视图
```

事件层是融合点。同一张公司行动表，运营视图用它解释价格跳空，日常视图用它提醒你该关注什么。
同样，`dq_results` 在日常视图里渲染成注脚，在运营视图里渲染成待办。写一次，两处用。

## 数据源

| 源 | 提供 | 覆盖 |
|---|---|---|
| yfinance | 日线、拆股派息、基础估值、前瞻财报日 | 港美股 |
| Nasdaq 公开日历 API | 前瞻除息日、登记日、派付日、拆股生效日 | 仅美股 |
| 港交所披露易 | 公告原文与 PDF 链接 | 仅港股 |

不追求覆盖度。免费源拿不到实时报价、盘口、逐笔、资金流、机构持仓、分析师预期。
**三十个敢拍胸脯的字段，比五百个不知道对不对的字段有用。**

## 用法

```bash
pip3 install yfinance duckdb pandas jinja2
```

```bash
PYTHONPATH=src python3 -m mdesk.pipeline
```

全链路：采集 → 前瞻事件 → 重算复权 → 跑规则 → 更新快照 → 渲染站点。

```bash
PYTHONPATH=src python3 -m mdesk.pipeline --render
```

只重渲染，不联网。改了模板或刚填完台账时用。

```bash
PYTHONPATH=src python3 -m mdesk.handle DQ-CA-001 9988.HK 2025-06-11 \
    --status explained --note "数据源用美元金额扣减港币价格，复权价以自算为准"
```

填写处理台账。人工判断记录用独立字段存放，重跑采集和规则都不会覆盖。

站点生成在 `site/`，本地预览：

```bash
python3 -m http.server 4173 --directory site
```

改自选股编辑 `data/watchlist.csv`，改跨市场对照编辑 `data/cross_listing.csv`，
改规则编辑 `sql/rules_seed.sql`。都不需要动 Python 代码。

## 已知缺口

1. **港股前瞻除净日依赖人工确认。**Nasdaq 日历只覆盖美股，披露易只给 PDF，本版不做 PDF 解析。
2. **无新股首日检查。**次新股页只能从行情起点反推上市时间，做不了首日字段完整性检查。
3. **单一行情源。**跨源比对无法进行。接入 akshare 作为第二源后可增加整个 cross-source 域。
4. **DQ-PRC-002 阈值未分层。**异常跳空阈值对全部标的统一取 20%，高波动标的误报偏多。
